Supplier Stack-Up Example data

Supplier partnership segmentation across four perspectives. Weight the criteria, adjust the scores, and watch the ranking and the segmentation map move. Everything stays in this browser; nothing is sent anywhere.

Criteria weights

0 = ignore, 10 = critical. The share shows how much of the final score each criterion carries. A knock-out hides any supplier scoring below it. The X / Y buttons decide which perspectives feed each axis of the map.

Import data

Paste CSV (or pick a file). First row: Supplier then one column per criterion. Optional rows: Perspective (which perspective each criterion belongs to), Weight (0-10) and Knock-out (minimum score). Every other row is a supplier with scores 1-5. Export first to get a template with the current criteria.
