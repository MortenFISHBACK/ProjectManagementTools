Import data

Paste CSV (or pick a file). First row: Supplier then one column per criterion. Optional rows: Perspective, Weight (0-10), Knock-out (minimum score), Definition, Score 1 means and Score 5 means. Optional columns: Comment: <criterion> and Overall note. Every other row is a supplier with scores 1-5. Export first to get a template with the current criteria.
